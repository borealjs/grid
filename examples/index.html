BorealJS Grid demos

Three demos of the same grid. This page and the reference server's /api run on port 5174.

React demo

The main showcase: React cells and filters, a custom backend, a pivot with merged cells, and a billion-row table with an Options panel.

Checking… Port 5175 · hot reload of the TypeScript sources

Plain JavaScript example

The grid with no framework, reading pivots and flat tables (up to a million columns) from the reference server.

Uses the built bundle: reload after a rebuild

Playground

Load a CSV or generate millions of rows, drag fields into rows, columns and values, set the latency, and watch timings live.

Its own server in a Web Worker · uses the built bundle

Commands

CommandWhat it runs
npm run devEverything: this server, the React demo, and a watch build of grid-core so the other two pages pick up changes on reload
npm startOnly this server (the plain JavaScript example and the playground), built once at start
npm run preview:demoThe React demo as published on GitHub Pages, with /api answered in the browser, at localhost:4173/grid/
