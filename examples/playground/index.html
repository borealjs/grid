1 · Data

Region › Country › City, Category › Product, Year › Quarter › Month and more, with seasonality, so pivots show real patterns. Extra columns become Attr N and Metric N.

Nothing is stored: the server computes each cell from its row and column number, so size costs no memory. The pivot has a fixed layout and its totals add up exactly. To arrange your own fields, use Generate or Upload CSV.
